## Immidiate goal
### Create NixOS Container for GOW 8-13-2026
I've been expanding the goals of this project and what I care about. As it stands, current
implemenntation is stable and a success. I have created a good "Cloud Gaming implementation"
and I can set a pathway of commecializing this (commercialization is just a concept I've been
playing around with). This influences what I want to work on next.

Looking at flakes, They are probably a good step, hoever what they really do is tighten
the bond between NIXOS and development. The global problem with this project is still
that not all emulatiors are developed in the enviornement I want to distribute. 

Therefore, as Summer is coming to a close and late fall, I want to spend more time on
this, the immidiate goal is shifting to GOW Nix container. I'm choosing this path because
GOW has better documentation for their conatainer developement and controller support is 
better. I'm killing 2 birds with one stone. 
I have a longterm goal of reducing size and nixpkgs have common dependences. GOW builds
from AppImages which work but duplicate dependencies. THis is another reason why I'm pursuing 
the NixOS container path.
